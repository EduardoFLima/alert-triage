# Diagrams

Each is an **editable SVG** — exported from [draw.io](https://app.diagrams.net)
with *Include a copy of my diagram* ticked — so the `.svg` reopens there as the
diagram that drew it. To change one: open the `.svg`, edit, export over itself.
There is no second file to keep in step, which is the whole reason for the tick.

`overview.drawio.svg` is used by the [README](../../README.md#architecture); the other
four by [`architecture.md`](../architecture.md).
